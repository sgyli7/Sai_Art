# 无头重载双臂平台：历史方案

**已淘汰：用户澄清任务是临时搬起重物，要求GD01级双足机甲，不是货运平台。I图只保留为洁净度参考。当前设计见 [双足举升方案](biped_lifter_design.md)。**

用户目标：单机搬运数吨以上，兼顾灾难救援、危险环境遥操作和安保。体量参照 GD01 级别，但不复制人形外观；取消独立头部。当前以 **5 t 低速载运** 为设计工况示例，这是待验证的目标，不是额定性能。

## 架构

整体约2.7 m高；宽、长初始布局目标约2.3 m、3.8 m，作业支撑展开后更宽。尺寸可随载荷和通行条件调整，不沿用此前1.55 m宽的概念值。上体为短而宽的无头躯干与两条工作臂，下体为低重心四轮承重车架。四个短行程轮架调平，常规移动由车轮承担；此轮不承诺双足步行或满载越障。

车架中部设置低位载货托架，载荷质心应落在轮胎接地区域形成的支撑多边形内。货物经支承垫、横梁、纵梁、轮架传到地面；双臂负责装卸辅助、夹持、定位和工具操作。**5 t载运目标不能被理解为任意姿态双臂举起5 t。** 臂端允许载荷、工作半径和工具力另行设计。

躯干布置在后部，能量与驱动模块低置。停驻作业采用制动、侧向展开支撑、工具反力回到车架。支撑脚垫需结合地基承载条件确定。救援末端可以替换为夹具、支撑/破拆工具；安保共用能力为态势感知、照明、遥操作与保护，不在本轮虚构武器性能。

## 功能细节与洁净审美

| 组件 | 为什么需要 | 图中应可读的细节 |
|---|---|---|
| 四轮承重车架 | 给低位载荷连续的负载路径 | 完整纵横梁、轮架、转向连杆、限位及密封接合 |
| 载货托架 | 支承与固定大件 | 承压垫、定位边界、成组锁定装置，支承面连续 |
| 双臂与工具快换 | 作业及定位 | 轴承/轴座、缸或驱动壳、整齐连杆、密封与单组工具连接 |
| 车架支撑脚 | 固定点作业扩大支撑面 | 可收纳滑梁、受保护执行器与大脚垫 |
| 嵌入感知模块 | 无头平台近场及环境感知 | 躯干和工具附近的小型窗口，避免双眼式脸或摄像头盒 |
| 低位能量/背部热管理 | 平衡、维护与散热 | 一体式维护盖板、独立成组散热区，不遍布打孔 |

细节来自这些装配的完整性。精密机构以银灰、蓝灰与橙黄分层，罩壳用连续暖白/蓝色大面及少量完整接缝。取消随机孔、点状黑纹、无归属小圈和假装旧化的线条。风格参考只决定绘制语言，不移植耳机、录音设备或建筑的具体形状。

## 验证边界

接下来的工程入口应是载荷包络和质心范围、静态倾覆边界、轮胎/车架/轴承强度、制动与坡度、臂端力矩及支撑反力，然后才是运动学与动力学。概念图不能证明其中任何项目已达标。此轮不修改 Sai_Lab 的控制、质量/惯量或 observation/action 数据。

现实产品证据与推论区分见 [调研](heavy_platform_research.md)。
