新机甲为无人、无头双臂双足结构。躯干顶部在肩线附近结束；感知位于小型嵌入窗口。肩部为紧贴承力关节的活动罩壳。手端为带宽接触垫的三指工业夹持手，脚端为宽实接地底板和可收纳后跟支撑。躯干、骨盆、髋/膝/踝的轴座和框架表达连续连接。

约2.7 m高是初始体量目标，真人用于近似尺度，图片不是测量图。宇树[官方介绍](https://www.unitree.com/cn/about/)确认GD01含乘员约500 kg并能双足/四足切换；未给出本轮可核实的完整尺寸或数吨举升指标。新图不复制其已验证物理参数，也不把外形概念写成宇树能力。

## 工况与负载路径

用户目标为单机数吨以上的**临时举升**。5 t可以作为后续验证的代表性工况，不能作为本图已证明的额定载荷。先限定静止、近身、低位、短行程的双手动作；举重行走、远伸和过顶举升需分别定义。

物体的承力台阶/夹持面 → 指垫与手架 → 腕、前臂、肘、肩 → 主躯干承力框架 → 骨盆 → 髋、腿杆、膝、踝 → 完整脚底 → 地面。双手从承力面下方支承，设计目标为正向承压连接，不单凭摩擦夹住重物。负载靠近身体，双脚宽站距，屈髋屈膝降低作业姿态；后跟支撑增加静止支承范围。实际接触、制动和支撑几何必须在模型中定义。

`biped_lifter_clean.png`展示外形；`biped_lifter_operation.png`展示双手近身、膝下低位举升。作业图离地间距比提示中的10–15 cm大，尚未严格控制行程；手指承压接触与后跟支撑的细部也需进一步几何定义。它表达动作，不能用图像推定物体质量、额定能力或稳定裕量。

## 细节与洁净

精密度由关节层叠轴座、密封、驱动壳、工具耦合、连杆、指节和维护接口承担。漆面由连续蓝/暖白大面及少量完整低对比接缝组成；紧固件只在实际可拆连接处成组出现。局部装配丰富与大面安静同时保留。
