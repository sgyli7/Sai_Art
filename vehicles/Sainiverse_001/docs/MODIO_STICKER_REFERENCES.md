# SnowRunner 贴花参考：Sainiverse 001

研究日期：2026-09-16。通过实际浏览器访问作者发布页并查看图库，未下载或运行 mod 文件。本次只借鉴标识的功能、形状和层级，不提取第三方贴图。

## 实际查看结果

普通网页抓取器在 mod.io 详情页只返回 JavaScript 提示；浏览器可正常显示作者说明及图片。以下视觉观察来自已显示的图库，非搜索摘要推测。

### Lore appropriate company logo stickers

作者 **RandoMulato**，页面说明含 23 个任务委托公司题材贴纸。作者注明素材混合 AI、Google clip art 与个人 Photoshop 编辑，其中 Tatra 是直接采用其标志；通过 Easy Sticker Generator 转换，并提到轻微法线让贴纸有贴上/涂上车体的感觉。[作者发布页](https://mod.io/g/snowrunner/m/lore-appropriate-company-logo-stickers)

实际查看首张车门拼图及第二张完整贴纸表：维修行业采用圆形人物徽章；货运采用矩形动物剪影章；油品采用倾斜字标和横向底带；农业采用植物符号加小副标题；另有六边形、竖排木纹和横向机构字标。重要借鉴点是“行业图形 + 不同外形 + 主副信息层级”，并非所有地方重复同一公司大字。贴纸在门把、门缝之间保留空隙，部分底色与车漆融合。

可复用性：页面提供已打包 mod 下载，但本次所读作者说明未显示源代码仓库、完整原始 PSD/SVG 清单或允许跨项目再分发的明确许可。混合来源也不能推断为已获全面授权。本项目仅做构图参考，不直接纳入素材。

### Easy Sticker Generator

作者 **nakedDave**。作者的流程是编辑固定名称、尺寸与格式的 TGA，再运行工具生成 PCT 文件以替换 SnowRunner 包内纹理。因此它主要解决格式转换与安装步骤，不是自动设计磨损或手绘风格的算法。[作者发布页](https://mod.io/g/snowrunner/m/easy-sticker-generator)

实际查看首图及第三图：首图在黄色发动机盖上放置单块手写涂鸦；第三图在红色盖板上放置黄色票据式矩形贴纸，外围黑黄棋盘边框，内部主标题、次标题、正文三级字号。可借鉴一张贴花内部的排版密度和局部位置，不照搬内容，也不把所有工业警示做成棋盘边。

可复用性：可见说明要求用户编辑包内 TGA，但未在该页面看到工具源代码仓库或允许把包内美术资产转移到独立项目的明确许可；本次未下载 EXE/ZIP，未检查包内许可证。

### In game asset stickers

同为 **RandoMulato**，作者说明 22 个贴纸来自游戏内公司、集装箱与车库资产，少量调整以适配贴纸。作者还指出部分透明素材更适合白色车漆，不能假设在任何背景色上都表现一致。[作者发布页](https://mod.io/g/snowrunner/m/in-game-asset-stickers)

实际查看首图：钢厂采用横向盾牌与斜体字组合；农场采用拱形文字、动物剪影和远离主体的小年代行；燃气公司采用圆章与下方两行字；另有大几何首字母配短名称。可借鉴“远处识别图形，中距离读名称，近处读小字”的三级阅读距离。

可复用性：作者明确素材来自游戏本体。页面可下载不等于有权向本项目再分发；本次未见跨项目复用许可，故不提取。

## 为本车设计的 9 类原创标识

下表是本项目原创布局建议，不是上述 mod 的现成内容，也不表达未经验证的额定载荷、认证或制造参数。

| 类型与文字 | 形状和层级 | 放置规则 |
| --- | --- | --- |
| **FIELD SERVICE / FS-01** | 小圆章，原创扳手与方孔组合；周边短字，中央编号 | 维修设备舱一处，避开门把与接缝 |
| **THERMAL LOOP / RETURN →** | 细长双线框，简化回路符号，红色细箭头 | 冷却罐/回流管对应盖板，方向由真实连接确定 |
| **FILTER ACCESS / FA-02** | 竖向窄矩形，抽拉滤芯图标，大编号、小说明 | 有滤芯维护逻辑的通风设备检修口旁 |
| **ROBOT BOARDING / KEEP CLEAR** | 横向板，原创小机器人轮廓与上下箭头；仅端部黑黄短条 | 升降台入口和外缘，对应实际登乘区域 |
| **CRANE 03 / PINCH ZONE** | 小三角警告图形 + 两行窄字 + 编号块 | 对应吊臂转台夹挤区；每台编号不同 |
| **MODULE B / CARGO DECK** | 切角矩形，模块字母最大，下方细字及连接图标 | 拖车服务侧；不虚构货重或认证数据 |
| **RECOVERY / TOW POINT** | 开口圆环与短箭头，单色厚墨线 | 仅实际牵引连接位置，不贴在装饰支架上 |
| **ISOLATE BEFORE SERVICE** | 红色小标题带 + 断开开关简图 + 黑白正文区 | 电气检修口附近，不等同新增可操作开关 |
| **CREW ENTRY / →** | 小拱顶门形轮廓，短字与方向箭头 | 驾驶舱真实入口，避开升降/楼梯交叠区域 |

Sainiverse 主品牌仍只保留少量醒目位置；上述服务、功能、模块、方向信息承担其余贴花密度。统一两套字体家族和有限线宽，以不同轮廓、图标、正负色块形成变化。每个母版生成轻/中/重三种局部腐蚀版本：字形、排版和边界不变，仅缺漆形状与位置变化。

落地要求：以现有材质图集/UV承载，不堆叠悬浮牌板；贴花留在指定面板内，不跨门缝、穿出边缘或压住活动铰链。黑、白、沙漠、蓝四主题分别检查明暗对比，必要时使用浅色/深色字的两套蒙版组合。近景看字形和局部岁月痕迹，远景看分区及节奏，不能靠全车高频噪点增加“丰富度”。
