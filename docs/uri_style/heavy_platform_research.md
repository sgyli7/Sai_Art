## 供主 Agent 判断的设计推断

以下是我们的概念推断，不是上述厂商已经验证的新机甲方案：

1. **取消头部是合理的功能收敛。** 感知可分布到胸部、肩侧及周边视角，光学器件做成小型嵌入组件；不需要巨大拟人脸或磁带状传感盒。具体视野、遮挡和保护仍需后续验证。
2. **先画出承载结构，再画覆盖件。** 原画应让夹持工具、腕部、作业臂根部、主机架、下肢或展开支撑到地面的连接关系可读。对重载工况，应区分移动与固定作业姿态；不要用细腰、细腕和大量暴露小机构来表达力量。
3. **巨型物体运输需要任务系统。** 可考虑与托架、承载滑橇、运输模块或多机协作配合，机甲承担定位、夹持、牵引、局部支撑等工作。不能把“巨物运输”直接等同于单机双臂举起巨物行走。
4. **丰富细节集中在有功能的区域。** 快换工具、支撑机构、关节维护入口、收纳槽和少数明确光学窗可以丰富设计。罩壳的大面保持连续、洁净；孔洞、螺钉及细线只出现在真实连接或检修位置，不随机铺满表面。此项是 URI 视觉要求，不是厂商工程结论。

## 本轮未验证项

新设计的总质量、静态/动态载荷、抗倾覆、地面压强、运动范围、工具兼容、热管理、续航与防护等级均未验证。图像可表现清楚的功能意图，但不能把这些指标标为既成能力。本记录不决定最终机构架构，不提供武器设计。
