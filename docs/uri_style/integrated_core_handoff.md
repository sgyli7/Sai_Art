## 组织与任务

顶壳、低位感知窗口、前部与侧面共用上身体块；肩部作为有界的侧后支架接入，短腰与骨盆承接，下肢保持厚实护罩和宽脚方向。整体形体先建立方向感，感知件嵌入其内部；大面具、独立头盔及膨大肩球已放弃。

用户重发的早期双足提供粗比例与较接近的机械体态；两张新工业概念参考提供上身语法。新图没有照用它们的武器、字样或旧化材质。URI原图始终作为STYLE。

无人双足双臂，约2.65–2.7m是本项目高度目标；临时近身搬起/挪动数吨重物是用户任务目标。没有货运底盘或默认武器。当前图片的真人比例仍未精确闭合，不能用画面反算实际尺寸。

## 工程接口

主承力框架需在感知罩壳后方连接肩与骨盆，手载荷经肩/腰/髋/膝/踝到足底，薄护罩与光学玻璃不作承重件。感知件需要完整器件、插头、线弯与散热包络；前倾壳体的近距离视场和任务遮挡必须检查，可按工况比较腕部相机。

粗腿包络分为结构连杆、驱动、轴承和分段护罩；已有[数量级初筛](leg_feasibility.md)仍有效，但未给本图完成供应商安装模型、全行程、质量惯量或稳定性验证。工况要区分静止短行程举升、地面拾取与带载行走。工具手需要正向承托/锁持，电源、制动、回馈热量、服务路径与急停需在实际装配落实。

Goose资料已按用户引用读取；已记录经验和文件读取哈希见[历史工程经验](helmet_body_handoff.md)、[goose_reference_manifest.json](goose_reference_manifest.json)。采用完整器件包络、任务姿态感知与同版制造源的方法；小型机器人结果不外推数吨能力。此次没有向Sai_Rotbots/Sai_Lab写入CAD、机器人或运行数据。
