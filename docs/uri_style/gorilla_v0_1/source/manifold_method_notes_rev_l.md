# Rev L：曲面生成研究与外观用途

用户明确要求复杂三维流形／高维投影的曲面语言，并否定用凹坑充当高级曲面。K 的纯凸面修补提示尚未调用，停止该路径。

依据 [Andrew J. Hanson 的方法说明](https://homes.luddy.indiana.edu/hansona/)，复方程 z1^5+z2^5=1 可用于卡拉比丘五次空间的局部二维截面可视化。这一截面嵌入四实维，再投影到三实维；它不是完整六实维空间，也没有在本研究计算 Ricci-flat 度量。

本次独立实现：取 z1=r exp(i phi)、z2=(1-z1^5)^(1/5) 的一个连续分支，进行正交 R4→R3 投影；原始投影图保留为 raw_fermat_projection_rev_l.png。为符合护具体量，对截面宽度与纵向定位进行外观适配，图为 manifold_projection_guide_rev_l.png。适配已改变度量，因此最终护具不能称为原始 Calabi-Yau 曲面或精确科学可视化。两者都只是绘画辅助，不是打印／CAD／运动／强度交付。

关键改变是使用复方程共同决定多个坐标，再从其投影关系获得截面与法向变化；与独立给顶面添加某个凹凸不同。主体方向、承力空间和美感仍优先，不能因为数学复杂就引入无意义洞、褶皱或曲线。图像生成携带该局部适配图，仅用作 GEOMETRY/FLOW；曲线网格、灰色材质、切边和数学图版不得复制为外观装饰。

计算源：build_manifold_study.py。采样误差、投影矩阵、域、面积正则性数值见 manifold_projection_study_rev_l.json；这些指标只检查辅助计算，不能证明 imagegen 输出精确遵守了曲面。Blender 源保持不动。
