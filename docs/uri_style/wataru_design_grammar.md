# 头身融合：从整体结构建立辨识

2026-10-01。依据用户连续反馈、魔神原画与本轮两张工业概念参考。以下是读图分析与本项目设计决定，不是原作者发布的设计哲学或性能结论。魔神图来源见[官方主力设定](https://www.mashin-eiyuuden-wataru.net/wataru1/mashin/01.php)。

## 最新纠正

用户要求的是浑然一体的连贯设计。此前“肩背在后上方、头面在前下方”的观察有空间关系上的价值，但落实成“完整巨面具取代胸腹”是错误收窄：U的大脸、肩球和骨盆各自占据独立体量，仍然像拼装器官。

用户新发工业参考并重发早期无头双足，明确早期机械体态/比例较接近；其问题是平顶胸箱与贴附感知窗口无法建立自然的头部辨识。需要重新组织整个上身，不是在既有胸箱上补一颗头或一张脸。

## 形体的共同工作

1. 顶壳、观察区及前侧过渡共享同一连续体块；它既容纳设备和保护结构，也表达面向、姿态和性格。
2. 头部意味可由前倾轮廓、保护眉檐、观察位置、侧面收束与上身体态共同形成。不要求人形嘴鼻、独立下颌或巨型面孔。
3. 肩连接从核心侧后自然接入，驱动罩只包覆必要包络，体量次于主形；低于肩的辨识区要清楚，不能靠把肩罩做成两个大球来满足高度线。
4. 上身体量在下方有明确腰部转折；骨盆承接重量，臂侧与髋旁保留运动负空间。外围机构丰富，主壳仍有完整大面与节奏。
5. 缩略图先读出整机方向、主次与机械体态，近看再看到有归属的感知、承力、密封和维护件。造型完整性先于面部细节数量。

魔神将头与短胸腹共享体量，工业参考将感知身份与机械躯干共享罩壳。其共性是整体组织与辨识共生；具体眉檐、比例与分面不同，不能照描任何一张的脸或饰物。

## 生成检查与纠正

V把旧胸箱作主输入，上身组织未改，只提高相机，主Agent已判失败。W取消旧上体输入，用两张工业图作结构语法；其上身连贯性发生变化，但旧化与长腿串入。X仅编辑W的表面、下部比例与前部末端，保留新上身核心；当前候选见[integrated_core_concept.png](integrated_core_concept.png)。

X仍不是用户审美认可或制造版本。头部意味是否自然、主形节奏是否足够优雅由用户评判；尺量目标、腿长度、真人比例与全运动包络尚未落实为CAD。完整提示、实际输入与SHA见[generation_manifest.json](generation_manifest.json)。固定URI通用规范保持v4.1，不把本机形体写成全题材要求。
