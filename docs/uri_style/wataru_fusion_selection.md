# 机甲造型筛选与工业融合

**初轮筛选记录：当时的“埋入上胸”解释已经被用户否定。** 最新用户以战神丸指出肩背在后上方、完整头面在前下方、短腹与腰侧甲向腿过渡；头体替代部分胸腹。现在以战神丸用户图为主、幻神丸为辅，提取空间语法而不照搬甲片。新解释与候选见[魔神设计理解](wataru_design_grammar.md)、[新设计交接](helmet_body_handoff.md)。下文旧决定只用于追溯，不作当前生成指令。

选择：第一部《魔神英雄伝ワタル》的 **幻神丸（Genjinmaru）**。这是对官方原图的造型判断，不是官方对工程能力或URI风格的评价。当前任务保留厚实双足比例、短躯干与洁净精密外壳，同时需要能识别的头部元素。

## 融合决策

保留当前 `biped_lifter_clean.png` 的骨盆、四肢、宽脚、身体比例、工业夹持手与洁净度。将上胸顶部重设计成共用罩壳：小幅抬起的圆润颅甲和保护眉檐，下面是嵌入的蓝灰光学视窗及暖白/银灰面罩；下颌与上胸保护领融接。脸约为躯干宽度的三分之一，主要埋在上胸，颈部不外露。这是新的工业感知/保护组件，不是把巨大人头放回去。

只迁移幻神丸的头胸组织；忍者高冠、背部手里剑、锐利肩饰、颜色和角色符号不进入设计。侧面/后方视野、头内机构转动、维护与遮挡后续需定义。临时举升仍通过双手、肩、主架、骨盆和双腿传到脚底。新的头部不改变载荷验证边界。
