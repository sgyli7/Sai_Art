## Original labels / algorithms

The nine service/equipment labels, semantic surface atlas, normal atlas and generation algorithms were authored for this vehicle. See source files for deterministic seeds and recipes. Trimesh, MuJoCo, Blender, Godot and the other tools retain their own licenses; dependencies are installed separately.

The exported engine extension API JSON and godot-cpp bindings are associated with the Godot project (MIT); godot-cpp is not vendored here. The dependency commit used for the tested native extension is recorded in BUILD.md.
