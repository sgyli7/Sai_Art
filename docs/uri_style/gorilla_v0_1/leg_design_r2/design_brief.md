# Gorilla 新版腿部造型 · R2

本版交付腿部造型、比例、关节位置和运动避让参考。打孔、轴承、材料壁厚、驱动选型与承载验算由「启动 Gorilla V0.1 工程方案」负责。此包不冻结制造参数，不覆盖工程项目的活动模型。

## 当前设计

- 真正三段 Z 型：髋—膝—中间折转—低脚踝；两个主要折转沿整条腿分布。脚踝至脚底不再增加一串短串联关节。
- 常态已经屈膝，参考段长为 680 / 680 / 500 mm；段长服务于折叠姿态，不再凑旧的 2.65 m 总高。
- 常态轴线相对向下竖直分别为 +45° / −70° / +40°；进一步屈膝为 +55° / −80° / +50°。每张视图使用相同几何与轴位。
- 小腿两侧连续支撑顺接低脚踝，脚底新设贯通的前后承托梁。脚尖、脚跟共同接地；脚掌整体重做，未沿用旧脚掌。
- 蓝色护罩随各连杆独立运动，膝后、折转处和脚踝有运动避让窗口。黄橙保留在大腿下端、关节细环与原有点缀；脚部暖白、承托层深灰。
- 上身、手臂与手部设计继续以已认可的 AA3 原画为准。本版主要修改腿脚。整机预览里的上身是 C15 原生参考粗模，未重新缩放，不能替代 AA3 原画。

## 比例与坐标

原生坐标为米制：X 向前、Y 向左、Z 向上。左右髋轴中心间距 780 mm。低脚踝轴心离地 178 mm。新足底长约 640 mm、最大宽约 310 mm。

与上身参考粗模组合后，常态约 2.264 m，进一步屈膝约 1.997 m。它们是当前造型模型尺寸，工程整机最终总高可继续按器件与体量调整。旧的 2.65 m 高度约束已经解除。

轴位、每个部件所属连杆、121 个姿态的变换和尺寸在 `source/leg_design_scene.json`。导入工程模型时先对齐髋轴、各段长度、脚底接地面，再细化内部结构。不要为重新凑旧高度而拉长连杆或站直。

## 交接边界

造型源提供外壳、关节包络、低脚踝和足底承托方向。其下的旧有限骨架只用于姿态与几何定位，旧骨架中的孔、壁厚和轴配合不是本版造型要求。没有将旧六缸布置带入本版：它虽曾在单腿台架中运行，合入整机后存在干涉，不能作为新版有效驱动方案。

工程侧需重新安排承力件和驱动，确认完整运动范围、足部实际自由度、质量惯量、载荷与疲劳；应在保持三段 Z 型、低脚踝、连贯承托和总体比例的基础上进行。实际数吨承载能力尚未由此造型包证明。
